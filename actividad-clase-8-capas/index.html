Cómo se trabaja

Sos el técnico que diagnostica antes de recomendar

Las 5 capas (repaso)

Aplicación → Sistema operativo → Controlador (driver) → Firmware/BIOS → Hardware.

Cuanto más abajo, más difícil y caro de cambiar.

La idea central

Un mismo síntoma («va lento», «se cuelga») puede originarse en cualquier capa. Diagnosticar bien es saber en cuál mirar antes de gastar tiempo o dinero.

En las partes 1 y 2 elegís una opción y aparece la corrección al instante. La parte 3 es de producción: la copiás a mano en tu carpeta (podés ver un ejemplo resuelto para comparar).

1
Diagnóstico

¿En qué capa está el problema?

Para cada síntoma, elegí la capa donde se origina. Al elegir aparece la explicación.

«La PC tarda en encender y, antes de que aparezca Windows, muestra una pantalla de configuración azul con la fecha y el orden de arranque.»

Firmware (BIOS/UEFI). Esa pantalla aparece antes de que cargue el sistema operativo: es el software grabado en la placa que arranca el equipo. Para conversar: ¿por qué no puede ser «una aplicación» si todavía no cargó Windows?

«Todo andaba bien, pero después de una actualización de Windows la placa de video empezó a fallar y se soluciona reinstalando su software específico.»

Controlador (driver). El driver es el que traduce las órdenes del sistema operativo a la placa de video. Si se rompe o queda desactualizado, el hardware está bien pero no responde como debería.

«El navegador se cierra solo cada tanto, pero el resto del equipo (otros programas, el sistema, el hardware) funciona perfecto.»

Aplicación. El problema está aislado en un solo programa; el resto de las capas funciona. Es la capa más alta y la más fácil de reemplazar o reinstalar.

«El equipo abre todo lento, hace ruidos al leer y la lentitud aparece con cualquier programa, no con uno solo.»

Hardware. El ruido y que afecte a todo apuntan al disco físico (probablemente un disco mecánico antiguo). Para conversar: ¿conviene comprar otra PC o alcanza con cambiar el disco por uno de estado sólido?

«El router se cuelga seguido y el fabricante recomienda actualizar el programa interno del dispositivo para solucionarlo.»

Firmware. El «programa interno» de un router es firmware embebido. Es el mismo concepto que la BIOS de una PC, pero en otro dispositivo. Para conversar: ¿qué riesgo hay si se corta la luz en medio de una actualización de firmware?

«Al iniciar sesión, el equipo tarda muchísimo porque arrancan automáticamente unos veinte programas al mismo tiempo.»

Sistema operativo. Qué programas arrancan al iniciar sesión lo administra el sistema operativo. Se resuelve por configuración, sin tocar el hardware. Para conversar: ¿por qué esta sería la mejora más barata de todas?
2
Clasificación

¿Qué grado de integración tiene cada equipo?

Recordá: baja = cada capa se cambia por separado · media = se actualiza software pero el hardware viene cerrado · alta (embebido) = todo viene como una unidad inseparable.

«Una PC de escritorio armada por partes: se le puede sumar memoria, cambiar el disco y reinstalar el sistema operativo.»

Baja integración. Cada capa es independiente y reemplazable. Es la más flexible y reparable, aunque ocupe más espacio y requiera armado.

«Una notebook: se puede actualizar el sistema operativo y algunos componentes, pero la mayoría del hardware viene cerrado de fábrica.»

Integración media. Hay margen para actualizar software y algo de hardware, pero menos que en una PC de escritorio. Es el equilibrio típico entre rendimiento y posibilidad de modificación.

«Un teléfono celular: se actualizan el sistema y las aplicaciones, pero no se puede cambiar el procesador ni, en general, la batería.»

Integración media. El software se actualiza libremente, pero el hardware viene sellado. Para conversar: ¿en qué se parece y en qué se diferencia de una notebook?

«Un router hogareño: hardware, firmware y software vienen como una sola unidad cerrada que no se puede abrir ni ampliar por partes.»

Alta integración (embebido). Es un sistema embebido: eficiente y compacto, pero difícil o imposible de modificar por partes. Si algo falla, casi siempre se reemplaza el equipo completo.
