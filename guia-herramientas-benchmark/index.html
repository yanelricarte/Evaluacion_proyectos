Herramientas de benchmarking: uso y lectura de resultados

Cuatro herramientas libres o gratuitas para medir con evidencia: qué mide cada una, cómo se usa paso a paso y qué muestra el resultado. Todas se pueden ejecutar en el laboratorio.

1CrystalDiskMark · disco 2Geekbench · procesador 37-Zip · procesador 4iperf3 · red
Antes de empezar

Medir bien: siempre igual, siempre repetido

La regla de reproducibilidad

Cerrá los otros programas, enchufá el equipo, repetí cada prueba 3–5 veces y tomá el promedio. Anotá la herramienta y su versión, la fecha y las condiciones. Sin eso, el número no es evidencia.

Sobre las capturas de esta guía

La de 7-Zip es una salida real (corrida en un equipo concreto). Las de CrystalDiskMark y Geekbench —apps de escritorio— son representaciones fieles del formato real: la captura definitiva se toma en el laboratorio con tus propios números.

Qué herramienta para qué parámetro (la «hoja» del top-down)
Disco / SSD → CrystalDiskMark Procesador → Geekbench · 7-Zip Red → iperf3 Tarea real (abrir, exportar) → cronómetro
1
Disco / SSD

CrystalDiskMark — velocidad de lectura y escritura

Código abierto · gratuita Windows · crystalmark.info

Qué mide: la velocidad a la que un disco o SSD lee y escribe datos, en MB/s. Es la herramienta ideal para la «hoja» del árbol cuando el cuello de botella parece el almacenamiento.

Para qué te sirve en una evaluación: decidir si conviene un SSD frente a un disco mecánico, o comprobar si un disco viejo es el que vuelve lento a un equipo.

Cómo se usa

  1. Descargá e instalá CrystalDiskMark desde el sitio oficial (o usá la versión portable).
  2. Arriba, elegí la unidad a medir (C:, D:, un pen drive…).
  3. Dejá el tamaño de prueba en 1 GiB y el número de vueltas en 5.
  4. Cerrá otros programas y hacé clic en All para correr todas las pruebas.
  5. Esperá a que termine y leé la columna de Read (lectura) y Write (escritura).
Representación del panel · la captura real se toma en el laboratorio

CrystalDiskMark 9.0.3 · 1 GiB · Unidad C: (SSD)

PruebaRead (MB/s)Write (MB/s)
SEQ1M Q8T13210.52980.1
SEQ1M Q1T12450.32100.8
RND4K Q32T1620.4540.2

Cómo leerlo: la fila SEQ1M (secuencial) es la velocidad para archivos grandes; la RND4K (aleatoria) pesa más en el uso diario del sistema. Un SSD da miles de MB/s en secuencial; un disco mecánico, ~100–160.

2
Procesador

Geekbench — rendimiento del procesador

Versión gratuita Windows / macOS / Linux / Android · geekbench.com

Qué mide: la potencia del procesador en un puntaje comparable entre equipos distintos, separando un núcleo (Single-Core) de varios núcleos (Multi-Core).

Para qué te sirve en una evaluación: comparar el procesador de dos equipos con un puntaje estándar, aunque sean de marcas o sistemas operativos distintos.

Cómo se usa

  1. Descargá Geekbench e instalalo (la versión gratuita alcanza para correr la prueba).
  2. Cerrá otros programas para no falsear la medición.
  3. Hacé clic en Run CPU Benchmark y esperá un par de minutos.
  4. Al terminar muestra dos puntajes: Single-Core y Multi-Core.
  5. Repetí 3 veces y promediá; anotá el modelo de procesador.
Representación del panel · la captura real se toma en el laboratorio
Single-Core Score
1 480
Multi-Core Score
7 400

Cómo leerlo: a mayor puntaje, mejor rendimiento. Single-Core importa para tareas que usan un solo núcleo (muchas apps de escritorio); Multi-Core, para trabajo pesado y paralelo (edición, compilación). Compará contra el otro equipo con el mismo criterio.

3
Procesador / memoria

7-Zip — benchmark integrado (sin instalar nada extra)

Código abierto · gratuita Windows / Linux · 7-zip.org

Qué mide: la velocidad del procesador y la memoria comprimiendo y descomprimiendo datos, en MIPS (millones de instrucciones por segundo). La ventaja: si ya tenés 7-Zip, no instalás nada más.

Para qué te sirve en una evaluación: medir el procesador en el laboratorio cuando no se pueden instalar programas nuevos, porque 7-Zip suele estar disponible.

Cómo se usa

  1. Opción visual: abrí 7-Zip File Manager → menú Herramientas → Benchmark.
  2. Opción consola: abrí la terminal y escribí 7z b (en Windows, "C:\Program Files\7-Zip\7z.exe" b).
  3. Dejá que complete varias pasadas y mirá la fila Tot: (total).
  4. Repetí 3 veces con el equipo sin otra carga y promediá los MIPS.

4
Red

iperf3 — ancho de banda real de la red

Código abierto · gratuita Windows / Linux / macOS · iperf.fr

Qué mide: cuántos datos por segundo pasan realmente entre dos equipos de la red (en Mbits/sec). Necesitás dos máquinas: una hace de servidor y la otra de cliente.

Para qué te sirve en una evaluación: comprobar si la red del laboratorio entrega la velocidad esperada, o comparar el rendimiento por cable frente al wifi.

Cómo se usa

  1. En la primera máquina (servidor), abrí la terminal y escribí iperf3 -s (queda esperando).
  2. Averiguá la IP del servidor (por ejemplo, 192.168.1.10).
  3. En la segunda máquina (cliente), escribí iperf3 -c 192.168.1.10.
  4. La prueba dura 10 segundos; leé la fila final receiver.
  5. Repetí 3 veces y promediá; anotá si fue por cable o wifi.
Ejemplo con el formato real de iperf3 · se ejecuta en el laboratorio
$ iperf3 -c 192.168.1.10
Connecting to host 192.168.1.10, port 5201
